TaskFlow
Project Report

A lightweight, browser-based task management application.
Built with HTML5, CSS3, and Vanilla JavaScript.

▶ Launch Live Demo →

01 Abstract

TaskFlow is a client-side web application that allows users to create, prioritize, filter, and manage personal tasks. The application requires no server, no framework, and no external dependencies beyond a web browser. All task data is persisted in the browser's localStorage API, ensuring information survives page reloads.

The project demonstrates core web development concepts including DOM manipulation, event-driven programming, data persistence, and responsive UI design.

02 Research Question & Objectives

Research question: How can a fully functional task management interface be implemented using only native browser technologies, without relying on external frameworks or backend services?

  • Design a clean, usable interface for task creation and management
  • Implement task prioritization (High / Medium / Low)
  • Enable filtering tasks by status and priority
  • Persist tasks across browser sessions using localStorage
  • Ensure the application works offline in any modern browser

04 Key Features

  • Add tasks with a text input and Enter key or button click
  • Assign priority level: High, Medium, or Low
  • Toggle tasks as complete / incomplete
  • Delete individual tasks or clear all completed at once
  • Filter view: All, Active, Done, High, Medium, Low
  • Live statistics: total, active, and done task counts
  • Data persisted in localStorage — survives page refresh
  • Fully responsive — works on mobile and desktop

05 Code Sample

Core addTask function — demonstrates input validation, data modeling, and state management:

function addTask() {
  const input = document.getElementById('taskInput');
  const priority = document.getElementById('prioritySelect').value;
  const text = input.value.trim();
  if (!text) { input.focus(); return; }

  tasks.unshift({
    id: Date.now(),
    text,
    priority,
    done: false
  });
  input.value = '';
  save();
  render();
}

Data is saved to localStorage after every mutation, and the render() function rebuilds the task list from state on each update.

07 Conclusions

TaskFlow demonstrates that a fully functional, persistent, and visually polished web application can be built using only the core browser platform. No build tools, no npm packages, no backend — just three files and a browser.

The project also illustrates the Model-View pattern at a micro scale: application state is stored in a JavaScript array, persisted via localStorage, and the UI is always a pure function of that state via the render() function.

Future improvements could include: drag-and-drop reordering, due dates with reminders, dark/light theme toggle, and export to JSON or CSV.
